# QUARTA-FEIRA

## Pulinho – jogo de plataforma

Jogo de plataforma simples que roda no navegador. Basta abrir o `index.html`.

- **← → / A D**: andar
- **Espaço / ↑ / W**: pular (segurar pula mais alto)
- No celular aparecem botões na tela.

Suba pelas plataformas até a porta lá no topo para ir para a próxima fase.
